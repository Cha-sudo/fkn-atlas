## Выполнение итераций 0/1 — 13.11.2026

Время наблюдений в БД — UTC; приведённые здесь часы — Москва (UTC+3). Рабочая среда Linux, Python 3.12.14, SQLite стандартной библиотеки, сеть доступна через настроенный proxy. Windows-машина пользователя и её GPU/локальные модели не обследовались. Дополнительные зависимости не устанавливались.

### Ревью и выполненные изменения

Исходные 9 тестов и baseline-demo прошли. Независимое ревью выявило схлопывание одинаковых ссылок, отсутствие исходных HTML, потерю истории при ошибках, зависание третьей прерванной попытки, неверную нормализацию `%2F`, отсутствие backoff и атомарного checkpoint. Эти дефекты исправлены. Последующее ревью выявило аварийные окна миграции/записи blob и старую цепочку редиректов при robots-denied; исправлены и покрыты тестами.

Версия 0.2.0: неизменяемые байты SHA-256, `snapshots`, `source_events`, вхождения `(snapshot_id, ordinal)`, постраничные транзакции, атомарная миграция v1, минимальная глубина очереди, `not_before`, backoff 30/60/120 с с учётом Retry-After, остановка хоста при 429/503, явные blocked/exhausted, проверка robots на редиректах, раздельные demo/scout, JSONL-экспорт. Гипотезы о предметной модели не создавались.

PYTHONPATH=src python -m fkn_atlas export --db runtime/pilot.sqlite --output runtime/pilot.jsonl
python -m compileall -q src scripts

Они не достигли лимита 8; четыре записи page:http_error сохранены как отдельные попытки. robots.txt в обоих случаях — 404. Ни одна ошибка не помечена done. Последующий report не запрашивает сеть. Сетевые проверки перед пилотом сохранены в runtime/research; отдельный аудит в SOURCE_SURVEY.md.

### Ошибки и ограничения

- Главная и архив fruitdet: HTTP 502, тело `Upstream wiki unavailable.`. Это не доказательство отсутствия материалов. В pilot.blobs сохранены тела ошибок, а не учебные HTML-снимки.
- Исходный wiki.cs.hse.ru: robots 301→/Robots.txt, затем 500; содержательная страница не запрашивалась. Взаимозаменяемость зеркал не установлена.
- YouTube: транспортный 403 туннеля; не следует приписывать его самому YouTube или утверждать, что видео недоступно пользователю.
- Предоставленная в handoff политика использования и список программ остаются сведениями документа, а не независимо проверенными заявлениями сайта.
- Проверен прототип одного worker. Нет полного дерева внешних ресурсов, загрузчиков PDF/видео, ASR, предметной модели программ/курсов, UI или реконструктора. Количество ожидаемых материалов неизвестно.
- Удалённые или изменённые данные не стирают снимки. Политика обновления завершённых страниц/ручного перезапуска exhausted — следующая работа; текущий scout продолжает незавершённые задания до 3 попыток.
