# Досье сопоставления 0.4.0

Существующий `Store` и каталог сохранены. `Reconciler(store)` добавляет пять таблиц `recon_versions`, `recon_materials`, `recon_gaps`, `recon_comparisons`, `recon_dossiers`. Таблицы содержат проверенные JSON-объекты, ссылки на прежние resource/blob ID и неизменяемую историю. Это ограниченный первый срез предметной модели.

Досье: `id`, `course`, массивы `versions`, `materials`, `gaps`, `comparisons`.

- Версия: `id`, `title`, `academic_year`, `program`, `stream`, `evidence`.
- Материал: `id`, `version_id`, `resource_id`, `title`, `kind`, `source_url`; для полученного — `input_sha256`; для извлечённого — `text_sha256`; после чтения — `review` с reviewer/summary/evidence. `topics` — явные тематические утверждения.
- Пробел: `id`, `version_id`, `title`, `reason`, `expected_topics`, `evidence`, `candidate_material_ids`, `status`, `limitations`. Причины: unlisted/link_missing/broken_link/access_blocked/not_transcribed/content_incomplete/not_checked. Статус: unresolved/partial_support/coverage_supported.
- Сопоставление: `id`, `left_id`, `right_id`, `status`, `scope`, `reason`, `limitations`, `reviewer`, `left_evidence`, `right_evidence`; необязательный `gap_id`. Статусы: verified/partial/additional/rejected/insufficient_evidence.
- Доказательство: `{sha256, start, end, quote, source_url}`. Позиции — индексы **Unicode-символов** в сохранённом UTF-8 тексте; `quote == text[start:end]`. Они не являются номерами страниц PDF или смещениями байтов.

Импорт проверяет SHA/размер blob, путь внутри blob store, принадлежность original ресурсу, связь производного текста с original и точные цитаты. Материал без извлечённого содержания допускается только в неопределённом сравнении. Утверждения о семантике остаются ответственностью указанного ревьюера: программная валидация не доказывает истинность заключения.

Для coverage_supported все явные expected_topics должны входить в scope подтверждённых решений для этого пробела и его кандидатов. Этот статус означает покрытие требований, а не получение отсутствовавшего исторического оригинала. Содержание исходного PDF может быть неполным, хотя все его страницы извлечены.

Повторный импорт идентичного ID/содержимого идемпотентен. Коррекция требует новых ID затронутых объектов и досье. По умолчанию отчёт выбирает последнее импортированное досье: старые решения не суммируются с исправленными. История доступна по `--dossier-id`, все таблицы включены в JSONL export. Один процесс записи в SQLite.

Ранжирование TF-IDF вычисляется по извлечённым текстам материалов той же предметной семьи из других версий. Названия не участвуют. Дубликат исходных байтов — вспомогательный признак, не доказательство совпадения разных частей одного документа. Оценка cosine — не вероятность эквивалентности. Реальная ограниченная оценка: [пилот линейной алгебры](research/LINEAR_ALGEBRA_PILOT.md).

Полные цитатные досье и учебные оригиналы хранятся вне публичного репозитория. Офлайн тесты используют синтетические документы; за реальные результаты они не выдаются.
