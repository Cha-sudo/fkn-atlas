# Автоматический сбор файлов: проверенная порция 1.1

16 ноября 2026 года. Это продолжение чистого проекта, без повторного reboot Git и без чтения старых вложений. Цель порции — автоматический переход по нескольким рёбрам до исходных учебных байтов, возобновление и строгая граница между обнаружением и педагогическим выводом.

## Реальный маршрут и результаты

Корень: [линейная алгебра и геометрия ПМИ 2024/25, пилотный поток](https://fruitdet.ru/wiki/Линейная_алгебра_и_геометрия_на_ПМИ_2024/2025_(пилотный_поток)). Использован уже сохранённый успешный снимок страницы. От него программа сама прошла ссылки «Лекции», «Алгоритмы», «Материалы» и индивидуальные задания. Корень автоматически не обновлялся.

Четыре ограниченные порции: 20/40/40/25 задач; всего 95 HTTP-запросов, включая robots; 1 798 697 принятых байт ответов. Остановка — лимит задач, очередь сохранена. После обнаружения прямые ссылки на файлы получают приоритет получения перед очередными страницами каталога; это технический порядок сбора, не рейтинг образовательной ценности.

Новые результаты относительно первой итерации:

- **23 исходных файла** из связанных репозиториев: 1 PDF, 17 TeX, 3 `.sty`, 2 `.gitignore`. Вспомогательные файлы не считаются изученными лекциями; TeX не компилировался.
- **65 ответов метаданных**: GitHub commit/tree, публичные ресурсы Яндекс Диска. Это не 65 скачанных учебных документов.
- Вся локальная коллекция теперь содержит 111 полученных объектов: 15 HTML, 69 JSON, 3 PDF, 24 текстовых файла. Всего 7 839 528 байт исходных объектов; SHA-256 каждого проверен.
- В области этого обхода допущен 151 ресурс: 91 done (включая 3 ранее полученных), 37 blocked по robots, 23 pending. В этой области сохранены ещё 16 переходов pending (13 контактов и 3 URL с непроверенными query) и 40 исключённых вхождений ведомостей. Эти числа не являются знаменателем всей Wiki.
- Глобально обнаружено 4198 URL, сохранено 5174 вхождения; 156 ресурсов имели попытку, 4042 ещё не запрашивались. Повторные вхождения не схлопывались.

Загрузки с `downloader.disk.yandex.ru` остановлены robots. Ни один такой ответ метаданных не объявлен полученным PDF. Оставшиеся 23 задачи сохранены; полнота папок не заявляется. Drive с параметрами остался pending; YouTube-видео в этой порции не получались.

## Новый содержательный результат

Автоматически получен [algorithms.pdf](https://raw.githubusercontent.com/DimaTrushin/LinearAlgebraAlgorithms/2e2abda67e76a20ba13e5ff349187e421889027b/algorithms.pdf): 476 797 байт, 21 страница; SHA-256 `eae3fd485e51d7a32e50d01a42d78560161c80f45763c4a46056c64204886235`. Ссылка на репозиторий прямо указана в целевой странице ПМИ; commit получен из публичного API, raw URL использует commit SHA, а не SHA дерева.

Прочитаны первые три страницы, но заключение ограничено разделом 1: постановка на с. 1, алгоритм и численный пример на с. 2. С. 2 визуально сверена. Независимое исключение Гаусса с точными рациональными числами и подстановка подтвердили две приведённые линейные комбинации. Это проверка другим методом в том же сеансе Codex, не заключение отдельного внешнего рецензента.

Седьмой индивидуально оценённый фрагмент выполняет функции демонстрации метода, приложения и разбора задачи: выбор базиса среди исходных векторов и нахождение координат остальных. Он добавляет конкретную практику к прежним шести фрагментам по Гауссу. Полного доказательства алгоритма и самостоятельных упражнений в выбранном фрагменте нет. Остальные разделы PDF содержательно не подтверждены. Размер, дата и продолжительность не использовались как оценка качества.

Этот материал относится к ПМИ. Перенос на КНАД не разрешён. Актуальное решение по старому кандидату остаётся rejected; полных и частичных восстановлений исторических занятий — **0**. Старое partial сохраняется только как отозванная историческая версия. Всего семь оценённых фрагментов; число сравнений и траекторий не увеличивалось.

## Проверки и оставшиеся границы

32 теста используют собственные фикстуры: корень → два курса → страницы материалов → общий файл, цикл, остановка/продолжение, запрет повторной загрузки, лимиты запросов/байтов/глубины, повреждённый PDF без остановки остальных ветвей, неизвестный redirect, правила контактов/ведомостей, GitHub commit/tree, пагинация Яндекс Диска и честные статусы листингов. Это отдельные проверки от онлайн-прохода выше. SQLite integrity/FK и контрольные суммы 111 объектов прошли.

Сохранены `crawl-live-1..4.json`, очередь SQLite, `LIBRARY.html` с переходами к локальным оригиналам, `REPORT.html`, `annotation-7.json`, расчёт `algorithm-example-check.json` и рендер страницы 2. Всё находится в приватном ATLAS_HOME, вне Git.

Большие видео пока не имеют потокового `.part`/Range-resume. Предел файла 32 MiB по умолчанию, до 128 MiB через CLI; превышение оставляет deferred. Бюджет байтов учитывает распакованные HTTP-ответы, не точный сетевой трафик. Парсеры документов работают в процессе: лимит времени ограничивает сетевой проход, но не является процессной изоляцией тяжёлого PDF. Неизвестные внешние redirect требуют уточнения scope. При усечённом GitHub-дереве полная рекурсия пока не реализована. Полнота папок Яндекс Диска не агрегируется автоматически, даже если получена последняя страница. Google Drive/GitLab, ASR/OCR, массовая смысловая проверка остаются следующими задачами.

Исключение для межкурсовой замены по прямому указанию источника пользователь допускает. Реализация пока отвергает все такие замены: прежняя произвольная цитата не подтверждала конкретного донора и разрешённый объём. Принадлежность материалу курса теперь фиксирует рецензент отдельно через `bind`; транзитивная достижимость не используется как принадлежность. Программа проверяет форму и происхождение доказательств, но не гарантирует истинность произвольного суждения рецензента.
