# Целевая модель данных

Не путать фактический `src/fkn_atlas/storage.py` (минимальный пилот) с целевой схемой ниже.

## Сущности
- `program`: образовательная программа + альтернативные названия/группы.
- `canonical_course`: дисциплина как семейство, не привязанное к одному году.
- `course_version`: конкретные год, семестр, поток, преподаватель, программа.
- `lesson`: лекция/семинар/лабораторная/экзамен/задача с темой и номером, возможными неоднозначностями.
- `source_page`: URL, снимок, время, статус HTTP, заголовок, хеш HTML.
- `resource`: канонический URL/ID провайдера, тип, метаданные, текущая доступность.
- `resource_occurrence`: откуда найдена ссылка, текст, html-context, программа/год/поток, время; несколько вхождений на ресурс.
- `resource_edge`: папка → вложенный каталог/файл, плейлист → видео, курс → материал, зеркало/альтернатива.
- `content_blob`: SHA-256, байты/формат, относительный путь. Без перезаписи оригиналов.
- `derived_artifact`: текст, OCR, ASR, слайды, embedding; исходный blob, извлекатель+версия, таймкоды, хеш.
- `processing_job`: состояние стадии, `attempts`, `not_before`, `error`, `updated_at`, checkpoint.
- `topic_claim`: принадлежность теме с доказательством, извлекателем, confidence и review-status.
- `gap`: пробел в конкретном `course_version`/`lesson` и его тип (нет в плане/нет ссылки/битая ссылка/нет записи/нет анализа).
- `replacement_candidate`: источник и недостающая тема; признаки соответствия, тип `candidate / partial / verified / rejected / insufficient_evidence`, доказательства и проверивший.

## Инварианты
1. Оригинальные файлы неизменны, дедупликация **только байтовая**; ресурс/URL/курс не сливаются из-за совпавшего blob.
2. Факт и гипотеза — разные колонки и статусы; `verified` требует содержания или исходного эталона, а не названия файла.
3. Два URL могут вести к одному файлу, один URL менять файл с течением времени; история замеров сохраняется.
4. Не храним временные подписанные ссылки на выгрузку или секреты в логах.
5. Все отчёты по покрытию содержат фактический диапазон дат/источников, определение знаменателя и число непроверенных.

## Пример записи о кандидате (логический, не фиктивная находка)
```json
{
  "missing": {"course_version":"LAAG-2023-MAIN","lesson":"sem-07","gap_type":"recording_missing"},
  "candidate": {"course_version":"LAAG-2022-MAIN","lesson":"sem-07","resource_id":"..."},
  "status":"candidate",
  "evidence":[{"source":"transcript","span":"00:12:34-00:20:00","claim":"рассмотрен тот же метод"}],
  "differences":["не проверены задачи после 35-й минуты"],
  "reviewed_by":null
}
```
Никакая строка из примера не считается реально найденной в Wiki.
