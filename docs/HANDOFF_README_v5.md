# ФКН Атлас — комплект передачи проекта в Codex (v5, 13.11.2026)

**Цель:** создать воспроизводимую систему для инвентаризации, анализа и реконструкции учебных материалов **всех** программ Wiki ФКН за все доступные годы, включая связанные внешние ресурсы. Не ограничиваться ПМИ, только URL или современным годом.

## Начать за 3 шага
1. Распакуй ZIP в новую папку на Windows, например `C:\Projects\fkn-atlas` (не поверх старого v4). Открой **эту папку** как проект в Codex Desktop, Codex CLI или VS Code с Codex.
2. Убедись, что в корне находятся `AGENTS.md`, `docs/PROJECT_BRIEF.md` и `prompts/01_START_CODEX.txt`. Codex автоматически использует `AGENTS.md`; остальные документы прямо перечислены в первом задании.
3. Скопируй **весь** `prompts/01_START_CODEX.txt` в Codex. Поручи работать в открытой папке и демонстрировать фактические результаты запуска.

## Что уже включено
- `AGENTS.md` — короткие постоянные инструкции без подавления автономии Codex.
- `docs/` — цели, охват, схема данных, доступ к источникам, реконструкция курсов, распределение задач, поэтапная разработка, проверки.
- `prompts/01_START_CODEX.txt` — первое конкретное поручение; `02_...` и `03_...` — задания следующих этапов **после проверки** результата.
- `src/fkn_atlas/` — **небольшой проверяемый Python-прототип**, не полноценный краулер. Использует стандартную библиотеку; содержит локальную демонстрацию и ограниченный онлайн-разведчик.
- `tests/`, `fixtures/` — автотесты и **вымышленные** страницы для проверки без интернета.

## Проверить прототип без интернета (Windows PowerShell)
```powershell
py -3 -m unittest discover -s tests -v
$env:PYTHONPATH="src"
py -3 -m fkn_atlas demo --db .\runtime\demo.sqlite
py -3 -m fkn_atlas report --db .\runtime\demo.sqlite
```
Либо используйте `python` вместо `py -3`. Предпочтительна Python 3.11+. В документации используются команды из **корня проекта**.

## Небольшой онлайн-пилот — только когда среда Codex разрешает сеть
```powershell
$env:PYTHONPATH="src"
py -3 -m fkn_atlas scout --db .\runtime\pilot.sqlite --max-pages 8 --delay 1.5
py -3 -m fkn_atlas report --db .\runtime\pilot.sqlite
```
Скрипт по умолчанию запрашивает только страницы в области `fruitdet.ru/wiki` и **не обходит внешние сайты**. Внешние ссылки сохраняются в каталоге как обнаруженные; обработчики облачных папок/видео — отдельный следующий этап. Реальный результат зависит от состояния сайта и сети.

## Что не сделано и НЕ должно называться готовым
Никакие реальные курсы или медиафайлы в пакет не скачаны. Локальный демопилот использует **исключительно фикстуры**. Нет распознавания видео, обхода Яндекс Диска, полноценного парсинга таблиц Wiki, поиска эквивалентных лекций, фронтенда и локального LLM. Это **область задач Codex**, а не скрыто выполненная работа.

## История решения
Пакет заменяет прежние комплекты `Wiki_FKN_Codex_Starter_v1–v4` и переносит их основные требования. Он отдельно различает: обнаруженные ссылки, реально полученные материалы, извлечённое содержание, проверенное соответствие курсу. Дата подготовки 2026-11-13.
