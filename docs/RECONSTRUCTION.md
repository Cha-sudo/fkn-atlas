# Протокол восстановления неполных курсов

1. **Плановый эталон.** Восстановить темы и типы занятий каждой исторической версии из программы, журнала/расписания, содержания Wiki; пробел нельзя утверждать только из-за пропущенного номера.
2. **Типизация пробела.** `unlisted`, `link_missing`, `broken_link`, `access_blocked`, `not_transcribed`, `content_incomplete`, `not_checked` — это разные причины.
3. **Поиск кандидатов.** Сначала файлы с одинаковым SHA-256 или ресурсным ID; затем тот же преподаватель/поток и год ±1; затем другие годы/потоки/программы по содержательным темам. Никаких жёстких ограничений ±1 в итоговом охвате.
4. **Сравнение покрытия.** Сверять аннотации/задачи/конспекты/текст/ASR/слайды, выделять фактически совпавшие темы и недостающие подробности. Не считать одинаковое название лекции подтверждением.
5. **Проверка.** Автоматизированные кандидаты — гипотезы. Независимый ревьюер получает **оригинальные источники и извлечённые фрагменты**, а не только вывод первого агента.
6. **Решение.** `verified`, `partial`, `candidate`, `rejected`, `insufficient_evidence`, с обоснованием. Дать возможность сохранять несколько дополнительных лекций, если они различаются полезными доказательствами/упражнениями.
7. **Сводный курс.** Создать производную учебную траекторию со ссылками на исходные версии, без перезаписи оригиналов и без ложных «исторических» лекций, написанных ИИ.

### Минимальная проверка на пилоте
Создать размеченную человеком или тщательно проверенную выборку из реальных курсов: подтверждённые совпадения, частичные совпадения, ложные совпадения по названию, неопределённые случаи. Измерять precision, recall и долю `needs_review` **на этой выборке**, не объявлять глобальную точность всей коллекции.
