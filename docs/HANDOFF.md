# Продолжение без памяти чата

Цель — личная интеллектуальная библиотека всех программ Wiki ФКН, всех доступных лет/потоков, включая внешние материалы. Сохраняйте исходники и альтернативы; сравнивайте содержание фрагментов, а не номера, даты, размеры и заголовки. Локальные модели не интегрировать. Обязательное уточнение пользователя: восполнять прежде всего версиями того же курса. Другой курс/программа допустимы как замена только при прямом указании в источнике целевого курса, иначе это дополнительное чтение.

## Что готово

Новый Python-проект с независимой корневой историей. Читайте README и ARCHITECTURE. Работают сохранение оригиналов по SHA, дерево HTML/вхождения, очередь/retry/lease, извлечение PDF/HTML/текста/notebook/VTT, консервативные адаптеры, FTS и лексические кандидаты, планы, точные доказательства, индивидуальные педагогические оценки, сравнения, траектория с предпосылками, приватный HTML-отчёт. Реальный результат и знаменатели: RESEARCH-20261116.md.

Исследовано шесть фрагментов реальных PDF ПМИ двух лет. Кандидат на замену недоступного комплекта КНАД из ПМИ отклонён: такого переноса целевой курс явно не разрешает. Первоначальный partial отозван новой записью rejected; историю не удалять. Ни полных, ни частичных восстановлений лекций нет. Сохранена отдельная траектория ПМИ из версий одного курса. 4080 URL и 119 строк плана не означают изученные материалы. Полноценного смыслового поиска/OCR/ASR/автоматической математической верификации нет.

## Где продолжать на исходном ПК

Все каталоги — соседние в `%USERPROFILE%/Documents/ChatGPT`:

- `fkn-atlas-reboot-20261116` — чистый код, отдельный Git; используйте явно, а не старый каталог handoff.
- `fkn-atlas-private-20261116` — `atlas.sqlite`, `objects`, `derived`, REPORT.html, pilot-manifest.json, candidate-run.json, annotation-1..6.json, gap-review.json, record_pilot.py, correction-20261116.json. Старые gap-review.json и manifest.review относятся к отозванному решению; актуально последнее решение из SQLite/report.
- `fkn-atlas-private-backup-20261116` — проверяемая копия исследовательских данных после закрытия соединений.
- `fkn-atlas-pre-reboot-20261116.bundle` — старый Git bundle.
- `fkn-atlas-restore-check-20261116.git` — проверочное восстановление bundle; старые исходники не читать без отдельной задачи.

В новом аккаунте сначала проверьте подключение GitHub и право записи именно в `Cha-sudo/fkn-atlas`. Код клонируется из `main`; исходные документы и база не опубликованы и автоматически в аккаунт не переходят. На том же ПК задайте ATLAS_HOME на существующий private-каталог и запустите `verify`, `report`, `fragments`, `trajectories`. На другом ПК пользователь переносит этот каталог приватным способом, затем снова `verify`. Без него можно воспроизвести получение из публичных URL отчёта, но точных локальных аннотаций в Git нет.

```powershell
Set-Location "$env:USERPROFILE/Documents/ChatGPT/fkn-atlas-reboot-20261116"
$env:ATLAS_HOME = "$env:USERPROFILE/Documents/ChatGPT/fkn-atlas-private-20261116"
.venv/Scripts/python.exe -X utf8 -m atlas verify
.venv/Scripts/python.exe -X utf8 -m atlas report
.venv/Scripts/python.exe -X utf8 -m atlas fragments
.venv/Scripts/python.exe -X utf8 -m atlas trajectories
```

Окружение создано Python 3.12.14 из runtime Codex. Если этот runtime больше недоступен, пересоздайте `.venv` из обычного Python 3.11/3.12 по README. В управляемой среде потребовалось `ATLAS_BENCHMARK_DNS_PROXY=1` для синтетического DNS 198.18/15; вне такой среды не включать. Токены в чат не запрашивать.

Авторизация пользователя на замену main дана явно; повторное подтверждение не требуется. Корневая история подготовлена с нуля. Для первой замены допускается только lease на указанный старый SHA. После первой успешной замены далее используйте обычные fast-forward-коммиты. Всегда проверяйте фактический remote HEAD и CI; не полагайтесь на текст этого файла вместо проверки.

## Следующий конкретный шаг

1. Откройте приватный REPORT.html и pilot-manifest.json. Проверьте источники шести фрагментов и сохранённые ограничения. Новая оценка добавляется как версия, не перезаписывает старую.
2. Для пробела КНАД ищите материал КНАД другого года либо импортируйте оригинальный PDF КНАД через `atlas import`. Не обходите запрет Dropbox. Сначала проверьте фактическое содержание, различия разделов и требований. ПМИ не использовать как замену без прямого указания КНАД. Отдельно найдите связанный с Wiki листок практики именно ПМИ для траектории ПМИ. Решение rejected пересматривается только при новых допустимых доказательствах.
3. Расширьте содержательный цикл на программу вне ПМИ/КНАД и материал магистратуры. Не выдавайте перенесённый каталог за изученные курсы.
4. Реализуйте пагинацию/вложенные каталоги Яндекс Диска и отдельную возобновляемую очередь извлечения. Сбор уже ограничен, но тяжёлый парсер документа пока работает внутри процесса; серверная эксплуатация не заявляется.

В базе восемь остановленных задач: шесть Dropbox, одна отсутствующая Wiki-страница, исторический домен с timeout. Последняя попытка исторического домена также содержит служебный диагноз ограничения старого выбора очереди; ошибка исправлена и покрыта тестом, предыдущие реальные timeout сохранены. Повторять эти задачи без изменения условий не нужно. Новые обнаруженные URL сохраняются без автоматической постановки всех в очередь.

Не запускайте record_pilot.py повторно поверх уже записанного пилота: это журнал однократной записи проверенных наблюдений, а не генератор фикстур. Для корректировки используйте JSON-аннотации и новые версии решений.
