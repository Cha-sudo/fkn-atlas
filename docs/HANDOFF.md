# Продолжение ФКН Атласа без памяти чата

## Текущий результат 1.3.1

Цель — личная интеллектуальная библиотека всех программ и исторических версий Wiki ФКН. Сейчас сохранена проверяемая промежуточная итерация, не завершённая коллекция. Читайте README, ARCHITECTURE и RESEARCH-SCOPED-20261116.md. Отчёты 1.1/1.2 описывают предыдущие контрольные точки.

Обязательное уточнение: восполнение ограничено версиями того же курса и программы с проверкой конкретного содержания. Другой курс может быть отдельным дополнением. Исключение для замещения возможно лишь по прямому указанию целевого курса, но отдельная проверка донора/объёма пока не реализована, поэтому код запрещает такое замещение. КНАД остаётся rejected, восстановлений КНАД нет.

Схема 4: `version_snapshots` связывает версию с конкретным snapshot/SHA. `bind` принимает snapshot_id, не resource_id. Старые две записи version_materials сохранены только как история, автоматически не подтверждены. Новый снимок того же URL не наследует принадлежность. Проверка применяется в candidates/review/compare. `candidates --lesson LESSON_ID` фильтрует принадлежность до ранжирования; без --lesson это supplementary_discovery, не поиск замены.

Реальный новый случай: слайды лекции 3 основного потока ПМИ 2023/24 и 2024/25. Сопоставлены страницы 3–4; страницы 5–10 версии 2024 добавляют четыре отсутствующие в полученном комплекте 2023 темы. Решение partial покрывает 6/9 подцелей (две уже были), три остаются открытыми. Отсутствие относится только к данному PDF, не ко всем материалам/устной лекции. Исторических лекций полностью не восстановлено. Сохранена отдельная траектория ПМИ с исходными фрагментами.

Также индивидуально прочитаны два примера импорта Python курса Экономики. Код не запускался. Год курса не установлен по источнику. Это самостоятельная траектория, не замена ПМИ/КНАД. Всего 14 оценённых фрагментов, а не 666 изученных материалов.
