# Проверка стартового прототипа перед передачей

**Дата:** 13.11.2026. **Окружение:** контейнер с Python 3; реальный Windows Codex не тестировался.

## Выполненные команды
```bash
python -m unittest discover -s tests -v
PYTHONPATH=src python -m fkn_atlas demo --db runtime/demo.sqlite
PYTHONPATH=src python -m fkn_atlas report --db runtime/demo.sqlite
```

## Фактические результаты
- **9 из 9 тестов прошли**. Проверялись нормализация URL, защита от не-HTTP и URL с секретами, область Wiki, классификация источников, заголовок/контекст HTML, игнорирование script, идемпотентность записи и восстановление очереди после прерывания.
- Офлайн-демо обработало **3 вымышленные HTML-страницы** из `fixtures/`, сохранило **6 вхождений ссылок** и **5 различных адресов** в SQLite.
- В демо встретились 1 ссылка на Яндекс Диск, 1 на YouTube, 1 на прямой PDF, 3 на внутренние страницы условного сайта. Во всех 3 страницах `state=fetched`, очередные задания `state=done`.
- Повторный запуск демо **не увеличил** число вхождений ссылок.

## Не проверено
- Реальный доступ к Wiki и её архиву из Windows-Codex, ответы robots.txt, реальное извлечение таблиц, правильность фактических курсов/лет.
- Реальные API Яндекс Диска и YouTube; скачивание/транскрипция медиа, архивы, LLM, поиск замен, GUI.

**Оговорка:** конкретный URL YouTube в тестовых данных прикреплён к **вымышленному** курсу как технологический тест ссылки; это не заявление о его фактической принадлежности к линейной алгебре. Данные фикстур не смешивать с результатами реального исследования.
