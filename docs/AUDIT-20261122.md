# Охват Wiki и учебного курса на 22 ноября 2026 года

Атлас охватывает часть Wiki. В личной базе есть 10 927 URL. У 2 397 сохранён хотя бы один снимок, у 262 зарегистрирована попытка без снимка, у 8 268 отсутствуют и снимок, и запись о попытке. Среди последних 3 475 ждут в очереди, для 4 793 задание не создано. Это счёт адресов в SQLite. При просмотре семинара в браузере отдельная исследовательская квитанция могла остаться вне этой базы.

## Где начинается недобор

Публичный MediaWiki API fruitdet.ru вернул 2 668 разных ID страниц основного пространства имён шестью порциями (500 × 5 + 168). Последний ответ завершил пагинацию. Для 16 ID в Атласе есть проверенный HTML того же хоста с соответствующим wgArticleId. Ещё для 1 320 заголовков известен прямой URL, для 1 332 такого совпадения не найдено. Это инвентарь статей конкретного хоста. Туда входят, в частности, страницы проектов. Число учебных файлов, видео и всех исторических ревизий из этого итога вывести нельзя. Аналогичный запрос к wikics.site вернул HTTP 503. Это зеркало ведёт собственную историю копирования. [Индекс fruitdet.ru](https://fruitdet.ru/wiki/api.php?action=query&list=allpages&apnamespace=0&aplimit=500&format=json&formatversion=2) · [Архив на wikics.site](https://wikics.site/Wiki_ФКН/Архив).

| Сохранённый указатель | Разных прямых URL | Есть снимок | Попытка без снимка | Нет попытки в SQLite |
|---|---:|---:|---:|---:|
| fruitdet.ru · главная | 190 | 3 | 25 | 162 |
| fruitdet.ru · архив | 1 334 | 22 | 5 | 1 307 |
| wikics.site · главная | 189 | 9 | 3 | 177 |
| wikics.site · архив | 1 334 | 44 | 2 | 1 288 |

Каждая строка использует свой знаменатель. На архивной странице fruitdet.ru 1 433 вхождения, часть URL встречается несколько раз. Обходчик принял 2 129 адресов без попытки по признаку учебного контекста и 1 297 по признаку учебной Wiki-страницы. У 1 722 адресов встречается решение о непроверенном параметре запроса, у 775 — о пределе глубины. Причины могут пересекаться у одного адреса. Отдельно встречаются навигация и ведомости. Для исторического wiki.cs.hse.ru в базе есть неуспешные попытки обращения к корню. Учебная работа велась прежде всего по основному потоку ПМИ, общий обход на контрольной точке был приостановлен.

## Что проверено независимо от счётчика обходчика

Из исходных байтов 61 HTML-снимка Wiki повторно выделены обычные HTTP(S)-ссылки в содержимом статьи. Мультимножества пар «исходный href, адрес назначения» сопоставлены с occurrences отдельно для каждого снимка. На 9 453 вхождениях пропусков и лишних вхождений не обнаружено. Повторные ссылки учтены с их кратностью. Проверка относится к сохранённому HTML и указанному типу ссылок. В общем графе 23 236 вхождений из разных источников и форматов.

2 399 снимкам соответствуют 1 909 уникальных объектов. По 2 231 снимку есть технический результат обработки, в том числе 107 результатов «только метаданные», 202 неподдержанных формата и 678 результатов с требованием визуальной проверки. 168 снимков пока без записи извлечения. В формальном реестре 104 индивидуально оценённых фрагмента со ссылками на 43 снимка. Дополнительные проверки по кадрам лежат в исследовательских журналах. 41 версия дисциплины и 730 записей плана относятся к каталогу всей библиотеки. Исходное состояние у 679 записей плана — «не проверено». Каждая из этих величин описывает свой этап.

## Что вошло в линейную алгебру ПМИ

Проверены опубликованные строки нумерованных лекций на десяти страницах **основного потока** fruitdet.ru. Для восьми из этих страниц в этот проход впервые получены байты с данного адреса. Для части лет в Атласе уже существовали копии с другого хоста. Граница текущего 2026/27 года — десять опубликованных строк. Более ранние совмещённые страницы 2015/16 и 2016/17 требуют разметки потоков по разделам и в таблицу не входят.

В 13 случаях SHA оригинала связан с фрагментом или документом в уроке, в 5 присутствует видеоплеер, в 2 есть прямая ссылка в основном тексте. Ещё 3 встречаются только в примечаниях к урокам, 2 — только в карте лет. Для остальных 272 автоматическая сверка прямую связь не установила. Она сверяет URL, устойчивые ID провайдера и SHA источника. Совпадение темы, общее содержание разных файлов и материал из другого раздела проверяются отдельно. Например, ноль в последней колонке за 2019/20 совместим с использованием листков того года из другого раздела страницы.

В строках первых четырёх лекций каждого года найдено **42 вхождения, из них 20 прослеживаются в основном тексте**. Состав и последовательность тем по годам меняются. Номер используется здесь только как граница выборки для ручной проверки. Вне строк лекций сохранено ещё 1 341 вхождение, включая задания, папки, внешние указатели и служебные ссылки. Их индивидуальная учебная классификация не закончена.

В самостоятельном архиве семинаров учтены **225 ID видео и 158 разных документов**. Для всех видео есть квитанция об ответе oEmbed, у всех документов есть оригинал с SHA. В основном тексте шести уроков задействованы пять семинарских записей и четыре документа из этих 158. Всего в уроках показаны 19 оригиналов документов и досок по SHA, включая лекционные материалы. На дату сверки ни один из 225 ID не был представлен адресом просмотра этого ролика в таблице ресурсов SQLite. Теперь единый приватный экспорт связывает каждый из них с курсом, группой, квитанцией и уроками использования. Видеофайл и объём просмотренного по этому признаку не определяются.

## Исправления и порядок дальнейшего разбора

В уроке 2 после сравнения DA и AD показан семинар БПМИ213 от 13 сентября 2021 года, 15:50. Повторяющиеся единицы на диагонали дают наглядный пример свободного блока. Перед видео о следе трёх множителей теперь открыто оригинальное условие задачи 4 с первой страницы листка семинара 2. Порядок ABC и BAC сверен визуально, существование контрпримера проверено точным умножением. У слайдов лекции 2 за 2020/21 проверено имя файла через публичную ссылку Dropbox. Для автоматического загрузчика маршрут закрыт robots.txt, а подключение Dropbox не получило файл по выданному ID. Состояние отражено в карте лет. [Урок 2 локально](http://127.0.0.1:8765/atlas-lessons/products-and-systems.html#diagonal-seminar) · [Карта материалов](http://127.0.0.1:8765/atlas-lessons/years.html#coverage).

Ближайшая предметная работа — разобрать 22 оставшихся вхождения из начальной выборки. Для каждого зафиксировать год, поток, задачу ученика, локатор в оригинале и решение: основной фрагмент, альтернативный разбор, дополнительная практика, материал для более поздней темы, дублирование в установленном объёме либо недостаточность данных. Начать с лекции 2 основного потока 2021/22: видеозапись, доска и слайды указаны в одной строке. Проверить их вместе по трудностям урока 2. Затем классифицировать 1 341 вхождение вне строк лекций начиная с семинарских материалов и задач к уже опубликованным урокам. Старшие темы сохраняют своё место в годовых версиях.

## Воспроизведение

В окружении проекта с настроенным `ATLAS_HOME` команда `python -m atlas coverage --ledger` перечитывает базу в одной транзакции только для чтения, сверяет HTML и шаблоны уроков и создаёт приватные файлы `derived/coverage-urls.jsonl` и `derived/coverage-pmi-lectures.jsonl`. У каждой записи плана есть исходный снимок и путь в документе. Единый реестр содержит также семинарские записи из отдельного каталога. URL и формулировки могут содержать приватные сведения; файлы остаются в личном хранилище.

Для сравнения с инвентарём сайта выполните `python -m atlas wiki-index fruitdet.ru`, затем `python -m atlas coverage --ledger --site-index "ПАПКА_ИЗ_ПЕРВОЙ_КОМАНДЫ"`. Отчёт проверяет SHA ответов API, цепочку продолжений и ID на том же хосте. В `derived/coverage-wiki-pages.jsonl` сохраняются постраничные результаты. Снимок текущей экспертизы, входные квитанции и исходные порции API находятся в приватном `derived/coverage-audit-20261122`. Для точечного получения уже поставленного в очередь адреса у команды `run` есть повторяемый параметр `--resource-id`; действуют обычные ограничения сети и хостов.
