# Доступность Wiki: проверенные факты

Сводка 14.11.2026. Источники наблюдений: `runtime/research/followup_wiki/results.json`, `results_extra.json`, `results_linked.json`; тела ответов и SHA-256 сохранены локально. Сетевые наблюдения выполнялись 13.11.2026, время в JSON — UTC.

## Основной источник

`fruitdet.ru/robots.txt` отвечает 404. Основная Wiki, архив и `/wiki/` отвечали HTTP 502 с телом `Upstream wiki unavailable.`; корень сайта отвечает 302. Ошибка повторилась в независимых ограниченных запросах и в краулере. В этот период публичный API Яндекс Диска и GitHub отвечали успешно.

Эти данные локализуют отказ на пути fruitdet→его upstream, но **не устанавливают внутреннюю первопричину**: нет доступа к серверным журналам fruitdet, конфигурации reverse proxy и состоянию upstream. Нельзя утверждать, что это точно DNS, сертификат, блокировка HSE или отключение сайта. Отсутствие материалов не доказано.

Оригинальный `wiki.cs.hse.ru/robots.txt` ранее перенаправлял на `/Robots.txt`, который возвращал 500. При повторной проверке произошёл read timeout. Содержательная страница оригинала после неуспешной проверки правил не запрашивалась. `wikicshse.ru/robots.txt` вернул 503; страницы этого кандидата также не обходились.

## Доступная альтернатива

Из независимого поиска обнаружен [wikics.site](https://wikics.site/Wiki_%D0%A4%D0%9A%D0%9D). Robots HTTP 200 разрешает обычный reference/search-доступ и запрещает обучение моделей; обработка использует только каталогизацию/исследование. Получены HTTP 200 и сохранены:

| Главная Wiki ФКН | 84 147 | в `wikics_site_main.json` и SQLite |
| Архив | 479 819 | `1943e941d8cf9974a8afa6b24f5c1585ef401b3a8516985a18420fa791384a9b` |
| Основы и методология программирования, ПМИ 2021/2022, основной поток | 43 862 | `161f66da7dece81a6ac227ab6893a16b80b28d876ae288bd781e2c0eb2c6ad79` |

Отдельно прочитана страница описания зеркала; она не включена в число трёх учебных/каталожных страниц. HTML явно помечен `data-source=stale`, главная/архив содержат даты снимков 12.11.2026. Зеркало названо независимым, его официальный статус не подтверждён. В SQLite источник — фактический URL wikics.site, origin=`mirror_stale`, сохранено исходное время наблюдения. Снимки не приписаны fruitdet.

В навигации главной фактически присутствуют ПМИ, ПИ, ПАД, КНАД, ЭАД, ДРИП, РИЦП, ПИРС, майноры/факультативы, Data Culture, магистратура и другие факультеты. Это наблюдаемые разделы страницы, не утверждение, что все их дисциплины собраны. Главная содержит 2026/27; архив — заголовки учебных лет 2014/15–2025/26 (12 лет). Отдельная предметная модель программ и версий ещё не построена.

Из трёх HTML сохранено 1 792 вхождения ссылок, 1 564 уникальных нормализованных цели. Числа включают навигацию и служебные ссылки; их нельзя называть числом дисциплин или материалов. Реально проверена одна страница курса сверх двух каталогов.

Страница курса 2021/2022 содержит ссылку на `justalge/another_python_tutorial` с контекстом «Программа курса и ноутбуки лекций». GitHub сообщает переименование того же репозитория в `justalge/Another-python-tutorial`. Прямых PDF/ZIP-ссылок в этих трёх страницах не найдено. Есть ссылка на публичный файл Яндекс Диска с контекстом «Конспекты лекций»; API подтверждает `book-python.pdf`, 676 098 байт, но скачивание остановлено правилами сервера загрузки. Эти ограничения не скрыты за названием файла.

## Повторная ограниченная диагностика 14.11.2026

Fruitdet: robots404, Wiki502 с тем же сообщением upstream unavailable. `envoy`/`Via: Caddy` не локализуют точную первопричину. YouTube robots: proxy CONNECT403, ответа origin не получено. Повторные запросы содержимого после запрета не выполнялись.

**Изменение:** wiki.cs.hse.ru robots → /Robots.txt → 404. После этого две оригинальные страницы линейной алгебры 2023/24 и 2024/25 получены HTTP200. Текст mw-parser-output совпал с зеркалом (35 055 и 35 407 символов), нормализованные упорядоченные ссылки тоже (208 и 260). Это конкретное подтверждение доступности и соответствия двух страниц, не всей Wiki. Сырые ответы, времена, SHA и события SQLite сохранены отдельно. За эту диагностическую серию — 9 запросов, без бесконечных повторов.
