# Линейная алгебра: первый содержательный пилот 0.4.0

Проверено 14 ноября 2026 года (Москва). Выбрана **«Линейная алгебра и геометрия», ПМИ и ЭАД, основной поток ПМИ, 2023/24 и 2024/25**. Есть две опубликованные последовательности по 34 лекции, самостоятельные учебные PDF и проверяемые различия. Выбор сделан после получения шести страниц трёх дисциплин за два года, а не по известности названия.

Результат — **частичная учебная реконструкция**: для двух пробелов 2023/24 найдены и прочитаны содержательные фрагменты из 2024/25. Полностью отсутствовавшие исторические лекции не восстановлены. Все исходные версии сохранены отдельно.

## Реальный механизм и его качество

Детерминированный TF-IDF ищет по содержимому, названия не участвуют; результат всегда `candidate`. Решение импортируется только с явным статусом, областью сравнения и доказательствами. Нельзя закрыть пробел без покрытия всех заданных тем. Повторный импорт идентичного досье ничего не дублирует; изменение утверждений требует новой версии ID.

На **пяти вручную проверенных запросах** полезный кандидат имеет ранги **1, 1, 1, 4, 8**: Hit@1 = 3/5, Hit@5 = 4/5. Это не оценка всей библиотеки. Особенно слаб поиск короткого плана против частичных слайдов. Precision/recall не заявляются: остальные пары не размечены исчерпывающе. Малой выборки недостаточно для глобальной оценки качества.

У 12 PDF обнаружена повреждённая кодировка кириллицы в текстовом слое. Создана отдельная производная версия с явно заданной, проверенной по изображению таблицей символов; оригинал и сырой результат pypdf сохранены. Это не OCR и не автоматическая проверка математических формул. Изменения символов и родительский SHA записаны. Скрипт `scripts/reviewed_text_map.py` не выбирает кодировку самостоятельно.

Ollama и локальные совместимые API не обнаружены; GPU-инструмент отсутствует. Для 12 текстовых документов локальная модель не требуется. Следующий обоснованный эксперимент — сравнить embeddings с текущими пятью случаями и расширить независимую разметку; установка модели не является выполненной работой.
