## Почему нет скачанных видео

Для выбранного MP4 размером 28 817 898 байт официальный API предоставил дескриптор загрузки. Однако `https://downloader.disk.yandex.ru/robots.txt` ответил 200 и `User-agent: * / Disallow: /`. Адаптер сохранил правила и остановился до запроса байтов. Аналогично остановлено получение PDF. Временные подписанные URL не сохраняются в БД/логах. Доступность файла через браузер пользователя не проверялась.

Следующий содержательный шаг — проверка остальных ноутбуков и сопоставление тем с планом курса; следующий инфраструктурный — контролируемое обновление каталогов и воспроизводимая библиотека с поиском. Большой видеоархив не загружался.
