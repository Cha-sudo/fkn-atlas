# Ревью и проверка пилота 0.2.0

13.11.2026. Независимое read-only ревью исходного и изменённого кода; интеграция и тесты основным исполнителем.

Исправленные исходные дефекты: одинаковые ссылки терялись; не было исходных байтов и истории; ошибка перезаписывала успешный sha; третья прерванная попытка зависала; robots failure не фиксировался; `%2F` менял смысл адреса; depth сохранял только первое значение; внешние redirects/служебные query/нестандартные порты пропускались; checkpoint был неатомарен.

Повторное ревью обнаружило и подтвердило исправления: миграция v1 при сбое теряла видимость legacy-данных, запись прямо в конечный blob оставляла частичный файл, отказ robots наследовал предыдущую цепочку редиректов. Добавлены BEGIN внутри executescript, rollback, temp+fsync+atomic publication и сброс цепочки до проверки robots. Дополнительный случай коллизии legacy ID также исправлен без удаления старых связей.

Итоговые 39 тестов покрывают эти регрессии; runtime/tests.log. Независимая проверка import_survey на временных данных подтвердила проверку SHA-256, отсутствие повторных событий и фиксацию metadata_only без Wiki-происхождения. Настоящая предметная структура Wiki остаётся непроверенной из-за HTTP 502.
