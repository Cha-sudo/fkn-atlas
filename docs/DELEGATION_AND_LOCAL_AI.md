# Делегирование субагентам и локальному ИИ

## Что делает главный Codex
Согласует архитектуру, интегрирует результаты, запускает тесты, контролирует исполнение по реальным источникам. Не поручает LLM вычислять то, что проверяется Python (URL, MIME, sha256, схема HTML, очередь).

## Уместное распределение субагентов (необязательно)
- **Source scout** (read-only): изучает структуру Wiki и типы внешних ссылок, даёт примеры и ограничения; пишет только `docs/research/SOURCE_SURVEY.md`.
- **Data auditor** (read-only): оценивает схему БД, происхождение, статусы и случаи потери контекста; пишет только `docs/research/SCHEMA_REVIEW.md`.
- **Quality critic** (read-only): независимо ищет слабые места пилота и тестов; пишет только `docs/research/QA_REVIEW.md`.

Главный агент отвечает за код и объединение. Не давать двум агентам править один файл. Если субагенты недоступны — выполнять те же задачи последовательно. Параллелизм не самоцель.

## Локальный ИИ как сервис, а не обязательный субъект
- Python получает/обрабатывает источники, локальная embedding-модель оценивает тематическую близость, локальная LLM классифицирует сложные случаи; Codex проверяет спорные результаты.
- Допустимые варианты подключения после проверки окружения: локальный Ollama HTTP API (`http://127.0.0.1:11434`) или иной **фактически установленный** движок. Не предполагать установленную модель и не скачивать гигабайты моделей без учёта ресурсов пользователя.
- Сначала сделать `HeuristicMatcher`, позже `EmbeddingMatcher`, затем `LLMVerifier` на идентичном интерфейсе; все результаты содержат `model_id`, настройки и ссылку на обработанные фрагменты.
- Прогонять измеримый эксперимент на одной размеченной выборке: точность/полнота, секунды/документ, VRAM/RAM, доля случаев для Codex. Сравнить с Python-only. Если локальная LLM ухудшает точность, использовать её только для генерации кандидатов.

## Системные оговорки
Ранее пользователь экспериментировал с запуском локальных ИИ, но здесь **не подтверждены** актуальная видеокарта, объём VRAM/RAM и установленный Ollama. Codex должен проверить среду через диагностические команды. Прототип обязан работать без GPU, API-ключей и внешних LLM.
