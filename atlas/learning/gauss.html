Какие изменения сохраняют решения

Первоисточник Преобразования строк · ПМИ 2020/21, лекция 3, с. 3

Пример Атласа. Рассмотрим два уравнения с тремя неизвестными.

x + 2y + z = 4
2x + 4y + 3z = 9

Вычтем удвоенное первое уравнение из второго. Коэффициенты и правые части удобно записать в одну таблицу. Числа за чертой тоже участвуют в вычитании.

1   2   1  │ 4
2   4   3  │ 9

Первую строку переписываем. Во второй последовательно получаем 2 − 2 · 1 = 0, 4 − 2 · 2 = 0, 3 − 2 · 1 = 1 и 9 − 2 · 4 = 1.

1   2   1  │ 4
0   0   1  │ 1
Первоисточник Почему решения сохраняются · ПМИ 2020/21, лекция 3, с. 4

Нижняя строка теперь говорит, что z = 1. Почему можно решать полученную систему? Прибавьте к новой второй строке удвоенную первую. Проверьте, что восстановится и правая часть.

(0, 0, 1 │ 1) + 2(1, 2, 1 │ 4) = (2, 4, 3 │ 9).

Каждое исходное решение удовлетворяет преобразованной системе. Обратный шаг показывает, что и каждое решение преобразованной системы подходит к исходной. Так же работают обмен двух строк и умножение строки на ненулевое число. Обмен можно повторить, а множитель заменить обратным.[1]

Первоисточник Прямой ход · ПМИ 2025/26, лекция 3, с. 9

Прямой ход метода Гаусса повторяет эту операцию исключения. Выбираем ведущий ненулевой элемент, обнуляем коэффициенты под ним и переходим к оставшимся строкам и столбцам. Нулевые строки помещаем вниз.[2]

Как прочитать все решения

Первоисточник Главные и свободные неизвестные · ПМИ 2022/23, лекция 3, с 1:07:22 · Выбор параметров с 1:18:23

У полученной матрицы ступенчатый вид. Первый ненулевой коэффициент первой строки стоит в столбце x, второй строки — в столбце z. Эти два столбца ведущие. В столбце y есть число 2, но ни одна строка с этого столбца не начинается. Поэтому y свободна.[3]

Положим y = t, где t — любое вещественное число. Из нижней строки получаем z = 1. Из верхней следует x + 2t + 1 = 4, то есть x = 3 − 2t.

Все решения имеют вид (x, y, z) = (3 − 2t, t, 1).

Проверка состоит из двух частей. Во-первых, подстановка даёт первое равенство (3 − 2t) + 2t + 1 = 4 и второе 2(3 − 2t) + 4t + 3 = 9 для любого t. Во-вторых, у всякого решения есть значение y. Если принять его за t, две строки вынуждают именно указанные x и z. Значит, ни одно решение не пропущено.

Три возможных исхода[4]

Первоисточник Схема числа решений · ПМИ 2023/24, лекция 4, с. 1
  • Если после приведения появилась строка вида 0 0 0 │ 5, она требует 0 = 5. Решений нет. Столбец после черты никогда не обозначает неизвестную.
  • Если противоречия нет и каждый столбец неизвестных ведущий, обратная подстановка даёт единственное решение.
  • Если противоречия нет и остались свободные неизвестные, каждой можно дать независимый вещественный параметр. Получится бесконечно много решений. Строка из одних нулей равносильна 0 = 0 и сама по себе только повторяет уже учтённые условия.

Проверьте себя

Задачи Атласа. Для каждой системы выполните преобразование строк и запишите, сколько решений получилось.

  1. x + y = 4 и x − y = 2.
    Проверить решение

    Вычитание первого уравнения из второго даёт −2y = −2. Отсюда y = 1 и x = 3. Оба столбца ведущие, решение одно.

  2. x − y + 2z = 1 и 2x − 2y + 4z = 2. Сколько независимых параметров понадобится?
    Проверить семейство решений

    Вторая строка после вычитания удвоенной первой равна нулю. Ведущий столбец соответствует x. Положим y = s и z = t. Тогда (x, y, z) = (1 + s − 2t, s, t), где s и t независимо пробегают все вещественные числа. Второе уравнение следует из первого.

  3. В предыдущей задаче замените правую часть второго уравнения на 3. Что изменится?
    Проверить совместность

    Вычитание удвоенной первой строки даёт строку с нулевыми коэффициентами и правой частью 1. Это противоречие. Ни одна тройка чисел не удовлетворяет обоим уравнениям.
