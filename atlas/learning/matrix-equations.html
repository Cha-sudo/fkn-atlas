Как прочитать AX = B по столбцам

Первоисточник Доска ПМИ 2021/22 · лекция 4, нижняя часть средней колонки · Слушать с 44:39

На доске X(1) обозначает первый столбец матрицы X. В произведении AX первый столбец равен AX(1). Сравните его с первым столбцом B, затем сделайте то же для остальных. Получаются равенства Ax₁ = b₁, …, Axₚ = bₚ, где xⱼ и bⱼ — столбцы. Во всех системах коэффициенты одни и те же. Каждому столбцу B нужно своё решение.[1]

Размеры подсказывают, куда ставить ответы. Если A имеет размер m × n, а B — m × p, то в каждом столбце решения n чисел. Поставив p таких столбцов рядом, получим X размера n × p.

Один проход Гаусса для двух правых частей

Первоисточник ПМИ 2021/22 · лекция 4, с 47:10 · Общая схема на доске

Запишите блок (A | B). Когда вычитаете одну строку из другой, продолжайте вычисление через черту до конца строки. Ведущие и свободные неизвестные определяйте по левой части.

Исходный числовой пример ПМИ 2022/23 · лекция 4, с. 4, одна правая часть

Продолжение примера в Атласе. Добавим вторую правую часть и начнём на один шаг раньше. Вычтите первую строку из второй. Слева исчезнет единица в первом столбце. Справа изменятся сразу два числа.

1   0   3 │ 1   0
1   1   1 │ 5   1
0   0   0 │ 0   0
Результат вычитания 
1   0    3 │ 1   0
0   1   −2 │ 4   1
0   0    0 │ 0   0

С первым столбцом справа получилась в точности система со слайда. При свободной третьей координате s решение равно (1 − 3s, 4 + 2s, s)T. Во второй системе правые части равны 0 и 1. Выберем её третью координату t и получим (−3t, 1 + 2t, t)T.[2]

Все матрицы X получаются при независимом выборе вещественных s и t.

Для проверки возьмите s = 0, t = 1. Умножение исходной A на столбцы (1, 4, 0)T и (−3, 3, 1)T возвращает (1, 5, 0)T и (0, 1, 0)T. Если потребовать s = t, именно это решение потеряется.

Что решает одна строка нулей

Первоисточник ПМИ 2022/23 · лекция 4, с 53:48, несовместный столбец

Измените в последней строке только крайнюю правую запись на 1. Теперь там 0 0 0 | 0 1. Первый столбец по-прежнему можно подобрать. Для второго требуется 0 = 1. Собрать полную матрицу X невозможно.[3]

Что меняется в XA = B

Первоисточник ПМИ 2021/22 · лекция 4, с 43:24, переход ко второму виду · Запись на доске

Неизвестную слева преподаватель обозначил буквой Y. Транспонирование меняет порядок множителей. Если наша неизвестная называется X, получим ATXT = BT. Решите это уравнение по столбцам и транспонируйте ответ. Каждый найденный столбец станет строкой X.

Пример Атласа. Пусть строки A равны (1, 0, 1) и (0, 1, −1), а строки B — (2, 3, −1) и (4, −1, 5). Здесь запись по строкам особенно коротка. Для строки (u, v) произведение (u, v)A = (u, v, u − v). Первая строка B требует u = 2, v = 3, и третье число действительно равно −1. Вторая даёт u = 4, v = −1 и 4 − (−1) = 5. Эти две пары и есть строки единственной матрицы X.

Проверьте себя

  1. В разобранном примере AX = B возьмите s = 1, t = 0. Запишите X и проверьте второй столбец произведения.
    Проверить столбцы

    Столбцы X равны (−2, 6, 1)T и (0, 1, 0)T. При умножении A на второй столбец выбирается второй столбец самой A, то есть (0, 1, 0)T.

  2. В примере XA = B замените число 5 во второй строке B на 6. Можно ли исправить вторую строку X?
    Проверить совместность

    Первые две координаты уже задали строку (4, −1). Её третья координата после умножения равна 5. При правой части 6 решений нет.

  3. Исходный пример для задачи ПМИ 2025/26 · лекция 4, с. 3, два свободных параметра
    На слайде у решения системы свободны вторая и четвёртая координаты. Вопрос Атласа: если записать справа один и тот же совместный столбец дважды, сколько параметров потребуется для общего решения AX = B?
    Проверить число параметров

    Четыре. Для каждого из двух столбцов X можно независимо выбрать две координаты. Совпадение правых частей позволяет брать одинаковые решения, но также допускает разные.
