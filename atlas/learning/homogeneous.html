Что меняется, когда справа стоят нули

Возьмём систему из предыдущего урока и заменим обе правые части нулями. Коэффициенты оставим прежними.

x + 2y + z = 0
2x + 4y + 3z = 0

Это однородная система. В матричной записи она имеет вид Av = 0. Нулевой столбец всегда подходит. Но исчерпывает ли он все решения? Вычтем из второй строки удвоенную первую. Получаем z = 0, а затем x = −2y. Значение y можно выбрать. Все решения имеют вид t(−2, 1, 0), где t — любое вещественное число. Уже при t = 1 решение ненулевое.

Когда ненулевое решение гарантировано

Пусть уравнений m, а неизвестных n > m. После приведения к ступенчатому виду ведущих столбцов не больше m. Значит, найдётся свободная неизвестная. Присвоим ей 1, остальным свободным неизвестным — 0 и вычислим главные обратной подстановкой. Полученный вектор содержит единицу. Обратная подстановка выполнима, потому что у однородной системы все правые части остаются нулевыми.

При n = m вопрос остаётся открытым до проверки коэффициентов. Например, уравнения x + y = 0 и 2x + 2y = 0 допускают решение (1, −1), а уравнения x = 0 и y = 0 определяют обе координаты однозначно.

Как одно решение задаёт точку отсчёта

Вернём правые части 4 и 9. Из урока 2 известно частное решение p = (3, 0, 1). Прибавим к нему найденный однородный вектор. Получим ровно знакомое семейство.

p + t(−2, 1, 0) = (3 − 2t, t, 1).

При t = 1 получается (1, 1, 1). Подставьте его в исходную систему. Если вычесть исходную точку p, останется (−2, 1, 0), который даёт ноль в обоих уравнениях.

Почему это даёт все решения

Пусть Ap = b и S — множество решений Av = 0. Проверим два направления.

  1. Для любого v из S выполняется A(p + v) = Ap + Av = b + 0 = b. Каждая построенная точка подходит.
  2. Возьмём любое решение u исходной системы. Тогда A(u − p) = Au − Ap = b − b = 0. Значит, u − p принадлежит S, и u = p + (u − p) уже входит в наше семейство.

Так получается формула все решения = p + S. Геометрически это перенос всего множества S на вектор p. Начальную точку можно выбрать по-разному. Если система несовместна, частного решения у неё нет и применять формулу нельзя.

Проверьте себя

  1. Найдите все решения x + y − z = 0, запишите их через два параметра и предъявите ненулевое решение.
    Проверить параметры

    Положим y = s, z = t. Тогда x = −s + t. Все решения имеют вид s(−1, 1, 0) + t(1, 0, 1). Например, при s = 1, t = 0 получается (−1, 1, 0). Координаты y и z однозначно возвращают оба параметра.

  2. Теперь замените правую часть на 2. Найдите частное решение и с его помощью запишите всё семейство. Может ли сумма двух решений снова удовлетворять этому уравнению?
    Проверить сдвиг и сумму

    Подходит p = (2, 0, 0). Прибавив семейство из первой задачи, получаем (2 − s + t, s, t). У суммы двух решений левая часть равна 4. У их разности она равна 0.

  3. У системы x + y = 1, 2x + 2y = 3 соответствующая однородная система имеет ненулевые решения. Можно ли перенести их и получить решения исходной?
    Проверить условие теоремы

    Вычитание удвоенного первого уравнения из второго даёт 0 = 1. Однородные решения существуют, но прибавлять их не к чему. Для формулы нужно хотя бы одно частное решение исходной системы.
