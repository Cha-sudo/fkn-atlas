# ФКН Атлас

Локальная образовательная библиотека с проверяемым происхождением материала. Чистый перезапуск 16 ноября 2026 года: код и схема созданы заново, старые данные не импортированы.

Первая законченная итерация: от страницы Wiki через внешний источник и исходные байты до постраничного текста, проверенных смысловых фрагментов, проверки кандидата и учебной траектории. Содержательные решения принимает Codex/рецензент по первоисточнику; программа хранит и проверяет основания. Автоматического «понимания всех скачанных файлов» здесь нет.

Восполнение ищется прежде всего среди исторических версий того же курса. Материалы другого курса/программы могут служить заменой только при прямом указании в источнике целевого курса. Иначе это дополнительное чтение, которое не закрывает пробел. В пилоте перенос ПМИ → КНАД отклонён; отдельное полезное сопоставление двух версий ПМИ сохранено.

Версия 1.3 добавляет поиск для конкретного пробела (`candidates --lesson LESSON_ID`) и проверенную принадлежность конкретного снимка/SHA, без наследования по изменяемому URL. [Новые реальные результаты](docs/RESEARCH-SCOPED-20261116.md).

Версия 1.4 сохраняет ограниченные диагностики PDF и версию парсера/шрифтов. `extract SNAPSHOT_ID --reprocess` явно добавляет новое извлечение, сохраняя прежние цитаты; поиск использует последнее извлечение каждого снимка. Добавление fonttools не устраняет все искажения формул и кириллицы: визуальная проверка остаётся обязательной.

В версии 1.4.1 HTML-отчёт открывает именно те редакции оценок, на которых основаны сравнения и шаги траекторий. В нём видны год и программа проверенной версии, снимок, локатор и основание решения о восполнении. Локальный импорт notebook работает и при исходном URL Colab без расширения.

В версии 1.4.2 обход записывает решения по ссылкам снимка одной транзакцией. Учебные наборы данных и файлы PostScript доступны в библиотеке оригиналов с отдельными статусами получения. Их содержимое не пополняет поиск по учебному тексту.

Команда `catalog` создаёт локальный HTML-каталог. В нём можно раскрыть программу, год, курс и занятие, увидеть темы, ссылки, их состояния и проверенные привязки файлов. Каталог хранится рядом с приватной библиотекой. Пример для PowerShell:

```powershell
.venv/Scripts/python.exe -X utf8 -m atlas catalog (Join-Path $env:ATLAS_HOME 'CATALOG.html')
```

Версия 1.1 добавила автоматический проход по учебным ссылкам до локальных файлов. Очередь и все вхождения сохраняются между порциями. Исключение для межкурсовой замены по прямому указанию пока технически закрыто: произвольной цитаты недостаточно, отдельная процедура проверки донора и разрешённого объёма ещё не реализована.

## Запуск на Windows

Совместный курс имеет одну карточку с версиями по годам. Она открывается из раздела каждой программы, для которой найдено прямое указание в источнике. В карточке линейной алгебры ПМИ и ЭАД раздел «Темы по опубликованным планам» ведёт к исходным занятиям пяти лет. В разделе «Разобранные фрагменты материалов» приведены результаты проверки оригиналов и границы каждого вывода. [Результаты и навигация](docs/HANDOFF.md).

Для поиска среди уже разобранных фрагментов используйте `find-fragments --lesson LESSON_ID`. Фильтр `--function proof` выбирает доказательства, `--function assessment` — задания на проверку знаний. `--outcome` дополнительно задаёт результат обучения из оценки фрагмента. Команда показывает страницы, исходные URL, SHA и годы проверенных версий того же курса. Пример с реальными идентификаторами и результаты 22 ноября приведены в [журнале передачи](docs/HANDOFF.md).

Нужен Python 3.11 или 3.12 и Git. В PowerShell:

```powershell
git clone https://github.com/Cha-sudo/fkn-atlas.git
Set-Location fkn-atlas
python -m venv .venv
.venv/Scripts/python.exe -m pip install -e ".[test,visual]"
$env:ATLAS_HOME = Join-Path $env:LOCALAPPDATA 'FKNAtlas'
.venv/Scripts/python.exe -X utf8 -m atlas init
.venv/Scripts/python.exe -m pytest -q
```

Чтобы слушать лекции внутри уроков, запустите локальный каталог с выбранным выше `ATLAS_HOME` и оставьте окно PowerShell открытым.

```powershell
.venv/Scripts/python.exe -X utf8 -m atlas serve-course
```

[Оглавление линейной алгебры ПМИ](http://127.0.0.1:8765/atlas-lessons/index.html) открывается на этом компьютере. В начале уроков 1–5 нажмите ▶ или выберите тему под видео. Для просмотра нужен доступ к YouTube. [Материалы по годам](http://127.0.0.1:8765/atlas-lessons/years.html) показывают, какие страницы или минуты исследованы для каждого из пяти уроков. При открытии сохранённой HTML-страницы с диска используйте кнопку «Смотреть и слушать … на YouTube». Чтобы остановить локальный каталог, нажмите Ctrl+C в PowerShell.

Активация окружения и изменение ExecutionPolicy не нужны. Если команда `python` открывает Microsoft Store, установите Python либо используйте полный путь к Python из текущего runtime Codex. См. [официальную документацию venv](https://docs.python.org/3/library/venv.html).

```powershell
.venv/Scripts/python.exe -X utf8 -m atlas seed 'https://fruitdet.ru/wiki/Wiki_ФКН' 'https://fruitdet.ru/wiki/Wiki_ФКН/Архив'
.venv/Scripts/python.exe -X utf8 -m atlas run --allow fruitdet.ru --budget 2
.venv/Scripts/python.exe -X utf8 -m atlas links --contains 'Линейная алгебра' --limit 10
# Используйте target_id из результата links:
.venv/Scripts/python.exe -X utf8 -m atlas follow RESOURCE_ID
.venv/Scripts/python.exe -X utf8 -m atlas run --allow fruitdet.ru --budget 1
.venv/Scripts/python.exe -X utf8 -m atlas report
.venv/Scripts/python.exe -X utf8 -m atlas verify
```

Для автоматического сбора используйте `crawl`. Повтор той же команды продолжает сохранённую очередь; полученные ресурсы повторно не скачиваются:

```powershell
.venv/Scripts/python.exe -X utf8 -m atlas crawl 'https://fruitdet.ru/wiki/Wiki_ФКН' --max-depth 6 --budget 20 --max-requests 40 --max-total-mib 128 --seconds 180
.venv/Scripts/python.exe -X utf8 -m atlas frontier --limit 30
.venv/Scripts/python.exe -X utf8 -m atlas library (Join-Path $env:ATLAS_HOME 'LIBRARY.html')
```

Допускаются ссылки в содержании образовательной Wiki, учебные файлы, ссылки с учебным контекстом и проверяемые публичные маршруты провайдеров. Каждый переход хранит основание. Меню, служебные действия и ведомости исключаются; сомнительные ссылки, неподдержанные папки Drive и неизвестные параметры остаются pending. Новый внешний учебный сайт не требует пофайлового вопроса пользователю; проверяются публичный адрес, robots, redirect и лимиты. Достижимость по ссылкам не присваивает материалу курс и не подтверждает его содержание.

`run` сохраняет прежний ручной режим с `--allow`; `follow` требует обнаруженное вхождение. `seed --refresh URL` явно разрешает повторное получение. Ошибки не стирают успешные снимки. Версия 1.2 пишет исходники потоково в `.part` и продолжает их через Range/If-Range при согласованном сильном ETag. По умолчанию: файл до 1 GiB, 128 MiB на порцию, квота исходников/.part 20 GiB, резерв диска 1 GiB. `transfers` показывает неполные загрузки; `resume RESOURCE_ID` сохраняет checkpoint, `seed --refresh` начинает заново. Обход не означает загрузки YouTube-видео; robots и ограничения доступа сохраняются. [Протокол, тесты и ограничения 1.2](docs/STREAMING-20261116.md).

## Материалы и исследования

```powershell
.venv/Scripts/python.exe -X utf8 -m atlas import 'D:/Library/lecture.pdf' --source-url 'https://example.org/lecture.pdf'
.venv/Scripts/python.exe -X utf8 -m atlas search 'Гаусса'
.venv/Scripts/python.exe -X utf8 -m atlas candidates 'ступенчатая форма свободные переменные' --lesson LESSON_ID --limit 5
.venv/Scripts/python.exe -X utf8 -m atlas render SNAPSHOT_ID 7 'D:/Library/page-7.png'
.venv/Scripts/python.exe -X utf8 -m atlas plan 'D:/Library/plan.json'
.venv/Scripts/python.exe -X utf8 -m atlas annotate 'D:/Library/fragment.json'
.venv/Scripts/python.exe -X utf8 -m atlas review 'D:/Library/decision.json'
.venv/Scripts/python.exe -X utf8 -m atlas trajectory 'D:/Library/route.json'
.venv/Scripts/python.exe -X utf8 -m atlas report-html (Join-Path $env:ATLAS_HOME 'REPORT.html')
```

Команды с ID и путями выше — шаблоны, не готовые идентификаторы вашей базы. Реальные результаты первой итерации: [отчёт](docs/RESEARCH-20261116.md). Форматы решений и возможности обработчиков: [архитектура](docs/ARCHITECTURE.md), [продолжение без истории чата](docs/HANDOFF.md).

`candidates` — лексический TF-IDF с символьными 4-граммами по содержимому. Без `--lesson` это поиск дополнительных материалов по всей библиотеке. С `--lesson` до ранжирования допускаются только конкретные снимки, проверенно привязанные к той же программе и курсу; соответствие тем и глубины остаётся непроверенным до содержательного review. Это не смысловая модель и не рейтинг качества. По умолчанию он исключает страницы каталога MediaWiki; `--include-plans` добавляет их. Математические формулы сверяйте на рендере. Уверенность, ясность, полнота, корректность и образовательные функции хранятся отдельно, без общей оценки качества.

HTML, PDF, текст, Jupyter и VTT/SRT читаются без исполнения кода. ZIP и Office пока только инвентаризируются. Видео без транскрипта остаётся непрочитанным. Яндекс Диск: публичные страницы каталога, продолжения offset, вложенные элементы и разрешённые публичные файлы; полный обход папки не объявляется по одной странице. В реальном проходе загрузки остановлены robots. GitHub: commit → дерево → исходные файлы; усечённое дерево отмечается неполным. YouTube: только oEmbed. Google Drive: существующий коннектор → оригинал → локальный import; `drive-listing URL response.json` сохраняет нормализованный список до 100 детей уже обнаруженной учебной папки. Полнота перечисления не выводится из короткого ответа, токены не требуются в чат. Сам CLI не подключается к аккаунту. GitLab пока остаётся ссылкой/локальным импортом.

Большие материалы, исходная SQLite, извлечённые тексты, подписанные URL и исследовательские фрагменты остаются в `ATLAS_HOME`, вне Git. Локальный HTML-отчёт также приватный. В публичной ветке — только код, собственные тестовые примеры, документация и агрегаты.

## Проверки и границы

Тесты проверяют историю снимков, повторные ссылки, возобновление и аренды задач, обход с циклами, лимиты, robots, точность цитат, привязку к курсу, поиск по действующей редакции оценки и навигацию по совместным курсам. CI запускает тесты на Windows и Ubuntu с Python 3.11 и 3.12. Реальный проход описан в [отчёте 1.1](docs/CRAWL-20261116.md). Потоковое возобновление и получение PDF из Drive описаны в [отчёте 1.2](docs/STREAMING-20261116.md).

Это рабочее сквозное ядро, а не завершённая библиотека всех программ. Не реализованы массовая смысловая аннотация, OCR/ASR, анализ доски видео, embedding-поиск, автоматическое доказательство корректности, персональный прогресс и наставник. Локальные модели не интегрируются.

Архив старой истории: [`archive/pre-reboot-20261116`](https://github.com/Cha-sudo/fkn-atlas/tree/archive/pre-reboot-20261116). Основная ветка заменяется только после проверяемой страховки. Настройки публичности не изменяются.
