# ФКН Атлас — 0.4.0

Проверяемый каталог учебных материалов всех программ и лет Wiki ФКН. Python 3.11+, SQLite, сохранение оригиналов и происхождения. Рабочая версия включает ограниченный Wiki-краулер, публичные адаптеры Яндекс Диска/YouTube/GitHub и безопасное извлечение текстов из учебных файлов.

**Содержательный результат 0.4.0, 14.11.2026:** сопоставлены версии линейной алгебры ПМИ/ЭАД 2023/24 и 2024/25. Получены оригинальные страницы Wiki и 13 учебных PDF; прочитано содержание 12 PDF. Зафиксированы 3 соответствия в явно ограниченном объёме, 4 частичных, два частично восполненных лекционных пробела. Полная реконструкция курса не заявляется: остаётся 31 пробел. [Отчёт, объединённая структура и ограничения](docs/research/LINEAR_ALGEBRA_PILOT.md).

Предыдущий пилот: 34 каталога и 488 MP4 Яндекса только по метаданным; 13 ноутбуков из GitHub, содержательно проверены два. Эти результаты сохранены и не смешиваются со статистикой нового курса. [Отчёт 0.3.0](docs/research/CONTENT_PILOT.md).

## Продолжить на Windows

```powershell
git clone https://github.com/Cha-sudo/fkn-atlas.git
cd fkn-atlas
py -3 -m unittest discover -s tests -v
$env:PYTHONPATH="src"
$env:PYTHONUTF8="1"
py -3 -m fkn_atlas demo
py -3 -m fkn_atlas report --db runtime/demo.sqlite
```

Код, тесты, история и документация находятся в Git. Учебные оригиналы, SQLite и сырые сетевые журналы исключены из публичного репозитория. Перед обновлением локальной библиотеки сохраните её БД и одноимённую папку `.blobs` вместе. Старые версии снимков не удаляются. Миграция БД в схему 3 происходит автоматически при первом открытии новой версией; старый код 0.2.0 новую схему не откроет.

Стандартной библиотеки достаточно для demo, краулера, ZIP, TXT/MD/CSV/Python, DOCX и Jupyter. Для PDF установите необязательный извлекатель:

```powershell
py -3 -m pip install "pypdf>=5,<7"
```

Чужой Python, notebook cells, макросы и команды из документов не выполняются. PDF разбирается в отдельном процессе с таймаутом; OCR и проверка формул не реализованы. Извлечение текста и содержательная проверка — разные состояния.

На Linux/macOS используйте `python` и `export PYTHONPATH=src`. Команды рассчитаны на распакованное/клонированное дерево с `fixtures/`; wheel-доставка demo не реализована.

## Команды небольшого пилота

После установки `PYTHONPATH`:

```powershell
py -3 -m fkn_atlas scout --db runtime/pilot.sqlite --max-pages 8 --delay 1.5
py -3 -m fkn_atlas yandex-scan --db runtime/pilot.sqlite --max-pages 20 --max-depth 2
py -3 -m fkn_atlas resources --db runtime/pilot.sqlite
py -3 -m fkn_atlas youtube-probe --db runtime/pilot.sqlite --video-id mROFPH8WKZg
py -3 -m fkn_atlas export --db runtime/pilot.sqlite --output runtime/pilot.jsonl
```

`yandex-scan` продолжает сохранённую очередь каталогов. Повторный запуск завершённой очереди не создаёт дубликаты. `--public-url` выбирает конкретную публичную папку; по умолчанию контрольный адрес из ТЗ. `yandex-probe --public-url URL` проверяет отдельный публичный файл или папку. `yandex-fetch --path "/путь/файл" --max-mib 16` запрашивает только предварительно проинвентаризированный файл, проверяет размер/SHA-256 и правила сервера загрузки. Максимум 32 MiB на один файл в этом пилоте.

`github-archive --repository owner/repo --source-url URL` получает ZIP конкретного коммита, только если репозиторий уже найден в сохранённой исходной странице. `extract --resource-id ID` повторяет локальное извлечение после установки зависимости или обновления извлекателя. `resources` сообщает отдельно каталоги, полученные файлы, вложения архивов, извлечённые тексты и содержательные проверки.

Внутренний краулер `scout` по-прежнему ограничен `fruitdet.ru/wiki`, максимумом 12 заданий за запуск и глубиной 4. Сохранённое независимое зеркало импортируется отдельно через `scripts/import_mirror.py` с проверкой хешей, исходного времени и пометкой `mirror_stale`; оно не подменяет основной источник. Этот скрипт требует локальных исследовательских ответов, которые не публикуются в Git.

HTTP/robots-ошибки записываются в БД и отчёт; успешный выход CLI означает завершение процедуры, а не доступность материалов. Очереди имеют backoff/Retry-After и до трёх попыток. Массовая загрузка, периодическое обновление завершённых каталогов и автоматический перезапуск exhausted пока не реализованы.

## Ограничения и доказательства

- Один worker на SQLite. Одновременные команды записи в одну БД не поддерживаются.
- Оригиналы адресуются SHA-256; все вхождения ссылок и связи сохраняются отдельно от физической дедупликации файлов.
- Для атомарной записи blob нужна обычная файловая система с hard links (например NTFS). Храните DB и `.blobs` рядом.
- ZIP проверяется целиком до чтения: пути, симлинки, шифрование, число/размер вложений и коэффициент сжатия. Вложенные архивы не раскрываются рекурсивно.
- Исходные снимки зеркала сохранены отдельно. Для двух страниц линейной алгебры проверены оригиналы; на всю Wiki это не распространяется.
- Ни одно видео не просмотрено полностью и не транскрибировано. Два лекционных пробела получили лишь частичное текстовое восполнение; отсутствующие исторические оригиналы не восстановлены.

## Сопоставление и локальный импорт

`reconcile-import --dossier FILE` проверяет SHA, происхождение текстов и точные позиции цитат, затем сохраняет версии, материалы, пробелы и решения. `reconcile-report` по умолчанию показывает последнее импортированное досье, `--dossier-id` выбирает историческую версию. `reconcile-candidates` использует только содержание и никогда не выдаёт автоматический `verified`. Изменившиеся утверждения сохраняются с новыми ID, прежняя история остаётся в БД.

Для продолжения по отдельной резервной копии данных (её нет в публичном Git):

```powershell
$env:PYTHONPATH="src"
$env:PYTHONUTF8="1"
py -3 -m fkn_atlas reconcile-report --db ..\data\research.sqlite --dossier-id la-2023-2025-pilot-v2
py -3 -m fkn_atlas reconcile-candidates --db ..\data\research.sqlite --material-id la2023-sheet2
py -3 -m fkn_atlas reconcile-import --db ..\data\research.sqlite --dossier ..\data\dossier.json
py -3 -m fkn_atlas export --db ..\data\research.sqlite --output ..\data\export.jsonl
```

`import-file --filename FILE --source-url URL --discovered-on PAGE` принимает разрешённо полученный локальный файл, если URL уже найден в сохранённом снимке PAGE. Необязательные `--expected-size` и `--expected-sha256` проверяют получение. Откуда взят файл, исходное вхождение ссылки и хеш сохраняются. Это путь для ручного скачивания на Windows и специализированных коннекторов; обход ограничений доступа не выполняется.

`scripts/reviewed_text_map.py` применяет явно заданную проверенную таблицу символов к конкретному текстовому артефакту, сохраняя новый результат и родительский SHA. Не выбирает кодировку автоматически и не проверяет формулы. Протокол досье: [RECONCILIATION](docs/RECONCILIATION.md).
